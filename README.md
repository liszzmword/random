# 팀 발표 순서 추첨기 🎲

팀 발표 순서를 랜덤으로 정해주는 웹 애플리케이션입니다.

## 기능

- 팀원 이름 추가/삭제
- 랜덤 순서 추첨 (애니메이션 효과)
- 반응형 디자인
- 초기화 기능

## 사용 방법

1. `index.html` 파일을 브라우저에서 열기
2. 팀원 이름을 입력하고 "추가" 버튼 클릭
3. 모든 팀원을 추가한 후 "순서 추첨하기" 버튼 클릭
4. 랜덤으로 정해진 발표 순서 확인!

## 기술 스택

- HTML5
- CSS3 (Flexbox, Animations)
- Vanilla JavaScript
